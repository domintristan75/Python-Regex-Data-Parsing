# Python-Regex-Data-Parsing

Used the re module to perform regular expressions on tracking numbers, order IDs, and SKU numbers

I used re.compile to make regex objects to then add them to a list (named patterns) in order to display only what matches the regular expressions

For loops were used to redact email matches for privacy and to return matches for the list of regular expressions

The result from running the code is a clean and parsed version of the original text only outputting the desired values (tracking, order Ids, & SKU)
